## 🇺🇸 English Version

### 🌟 About the Project
**MX Production** is a high-performance, secure web platform crafted from scratch by **Yuseef Sinan**. It is designed for seamless media handling, precise audio/video mixing controls, interactive track management, and ultra-secure relational user authentication.

### ✨ Core Features
* **Cryptographic Authentication:** Complete sign-up and log-in architecture leveraging `bcrypt` for salted password hashing.
* **Advanced Media Management:** Full support for uploading, streaming, and previewing audio/video files (up to 3 hours duration).
* **Interactive Mixer Interface:** Dynamic track control supporting individual channel muting, volume adjustment, and playback options.
* **Comprehensive Account Panel:** Secure settings allowing users to modify usernames, update passwords, or delete accounts permanently.

## 🇸🇦 العربية

### 🌟 عن المشروع
**MX Production** هو منصة ويب قوية وآمنة لإدارة الوسائط وإنتاجها، تم تطويرها بالكامل بواسطة **Yuseef Sinan**. تم تصميم النظام لتقديم تحكم سلس في الصوت والفيديو، مع مصادقة آمنة للمستخدمين وإدارة متكاملة للحسابات.

### ✨ الميزات الرئيسية
* **مصادقة مشفرة وآمنة:** نظام تسجيل وتسهيل دخول متكامل يستخدم خوارزميات `bcrypt` لتشفر كلمات المرور بحماية عالية.
* **إدارة متقدمة للوسائط:** دعم كامل لرفع وتشغيل ملفات الصوت والفيديو (حتى 3 ساعات مدة الملف).
* **واجهة خلط تفاعلية:** تحكم ديناميكي في المسارات، كتم الصوت الفردي، والتحكم في مستويات الصوت.
* **لوحة تحكم الحساب:** إعدادات آمنة تتيح للمستخدمين تحديث أسماء المستخدمين، تغيير كلمات المرور، أو حذف الحسابات نهائياً.
